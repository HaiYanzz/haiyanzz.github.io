# 2026-11-26

## 个人博客静态化改造

- 起点：仓库只有一个手写 `index.html`。方案获批后改为「Markdown 写作 + 单脚本生成」的纯静态博客，无 Hexo / Jekyll / npm 构建链，无后端。
- 目录归纳（用户特别要求）：`assets/css/style.css` 放全部样式，`assets/js/main.js` 是唯一的 JS（代码块复制按钮），`scripts/build.py` 是生成脚本，`content/` 放原文，`posts/` 放生成产物。
- `scripts/build.py` 仅用 Python 标准库，自带极简 Markdown 解析（标题/段落/列表/引用/分割线/代码块/行内代码/链接/图片/粗斜体），生成首页、文章页、作品页、关于页。
- 写作约定：`content/posts/YYYY-MM-DD-标题.md`，正文第一行 `#` 为标题，第一段为摘要；无需 front matter。作品写 `content/works.md`，简介写 `content/about.md`。
- 发布流程：改 content → `python3 scripts/build.py` → `git push`，GitHub Pages 自动更新。
- 验证：4 个页面全部生成，相对链接与 CSS/JS 资源无缺失；`node --check` 与 `python3 -m py_compile` 均通过。
